# Plan for version 2.3.0

## feature:

- 粘贴时间轴：把 B 站视频简介或评论里的时间轴（每行“03:21 掏耳”）粘贴进跳转点面板，
  一次加好全部跳转点和名字
- 片段切换时淡出淡入：播放列表里截在中间的片段放到结尾时先淡出，下一条从中间开始时再淡入，
  切换不再生硬

状态：已实现并合并（PR #10），随 2.3.0 发布；和计划不同的地方见第 10 节

### 1. 目标

两项都是为了睡前闭着眼听：

- 长录音的跳转点现在只能边听边按 `b`，再一个个改名。B 站的 ASMR 视频往往在简介或评论里
  已经有人整理好了时间轴，复制过来就能一次加好。
- 2.2.0 的片段播放列表里，片段截在声音中间：放到结尾时声音被一刀切断，下一条又从另一段声音的
  中间突然开始。快睡着时这种突变很容易把人惊醒。

### 2. 用户决定（2026-10-17）

1. **范围**：这一版只做这两项。2.2.0 之后讨论过的其他想法（耳机按键在跳转点之间切换、
   读文件内嵌章节、一键设起点终点、播放列表的改名导入导出、响度均衡）都不做，见第 8 节。
2. **输入方式：粘贴框**。在跳转点面板里打开一个多行输入框，把时间轴粘贴进去。
   `Enter` 换行，另用一个键确定，这样 Windows 上逐键送来的多行粘贴也不会粘到一半就提交。
   不读系统剪贴板（要加依赖，SSH 下也用不了），也不读音频旁边的文本文件。
3. **先淡出再淡入，不做交叉淡化**。上一条淡到无声，装载下一条，下一条再从无声淡入。
   两条重叠着一边变小一边变大要让播放器同时放两个文件，改动太大；两个不同的双耳场景
   叠在一起几秒，睡前听也未必舒服。
4. **淡出时长是设置**：`playback { clip-fade 3 }`，单位秒，0 关闭；淡入用它的三分之一
   （默认 1 秒）。

### 3. 粘贴时间轴

#### 打开

- **`B` 在没有跳转点的录音上也打开面板**。现在没有跳转点时 `B` 只提示
  “这首还没有跳转点，按 b 在当前位置添加”；粘贴时间轴恰恰多用在还没有跳转点的录音上。
  - 能打开的条件不变：正在播放或暂停中、10 分钟以上的录音。
  - 空面板只有一行暗色说明：“还没有跳转点：b 在当前位置添加，v 粘贴时间轴”。
  - 面板里的 `Enter`、`a`、`s/S`、`e`、`d` 在空面板上什么也不做。
  - 删掉最后一个跳转点后面板不再关闭，变成空面板。
  - 换了曲目时（`sync_marks_panel`）：新曲目用不了跳转点才关面板；没有跳转点只是变成空面板。
- `{` / `}` 没有跳转点时的提示改为“这首还没有跳转点：b 在当前位置添加，或在 B 里粘贴时间轴”。
- **面板里按 `v` 打开粘贴框**（v 取“粘贴”Ctrl+V 的联想）。

#### 粘贴框

- 居中，宽 76 列，最高 18 行；标题“ 粘贴时间轴 · 曲名 ”。
- 内容是粘贴进来的原文，只能在末尾输入和退格，和现在的输入框一样不做光标移动。
  - 放不下时显示最后几行，光标总在末尾。
  - 能认出时间的行正常显示，认不出的行用暗色，一眼看出哪几行会被加进去。
  - 还没有内容时显示暗色的示例：“每行一个时间和名字，例如 03:21 掏耳”。
- 下面一行实时显示识别结果，例如“认出 12 个：新增 10 个 · 2 个已有 · 1 个超出时长”；
  一个也没认出时写“还没有认出时间”。
- 按键：

| 按键 | 操作 |
|---|---|
| 字符 | 输入 |
| `Enter` | 换行 |
| `Backspace` | 删掉最后一个字符 |
| `Ctrl+S` | 添加，回到跳转点面板 |
| `Esc` | 取消，回到跳转点面板，内容不保留 |

- `Ctrl+S` 在 Linux 上不会被终端当作暂停输出：进入 raw 模式时 crossterm 已经关掉了 XON/XOFF。
  Windows Terminal 也会把它交给程序。
- 内容最多 64 KiB，超出的部分不再接收，提示“内容太长，只保留了前面的部分”。

#### 终端粘贴

- **Linux 打开 bracketed paste**（`EnableBracketedPaste`），粘贴的内容作为一整段
  （`Event::Paste`）送来，不会被当成一串按键。
  - 退出、出错和 panic 恢复终端时一并关掉。
  - 换行统一成 `\n`（`\r\n`、`\r` 都换掉）。
- **Windows 不打开**：crossterm 在 Windows 上按控制台 API 读按键，打开以后终端会把粘贴包在
  转义序列里送来，其中的 Esc 会被当成“返回”。Windows 上粘贴仍是逐键送来的，`Enter` 换行，
  所以照样能用。
- 粘贴的内容按当前焦点处理：
  - 粘贴框：接在末尾。
  - 单行输入框（搜索、新建列表、跳转点改名、条目改名）：换行和制表符换成空格，去掉末尾的空白，
    接在末尾。打开 bracketed paste 以后不这样做，往搜索框里粘贴就失效了。
  - 其他地方：忽略。现在在曲库里不小心粘贴，会把内容当成一串快捷键执行；以后不会了。

#### 识别规则

每行最多认一个跳转点：

- **时间**：一行里的第一个时间。
  - 写法：`m:ss`、`mm:ss`、`mmm:ss`（分钟可以超过 59，长视频常这么写）和 `h:mm:ss`；
    后面可以带 `.毫秒`。秒要小于 60，`h:mm:ss` 里的分钟也要小于 60。
  - 冒号可以是全角的 `：`，数字可以是全角的 `０–９`。
  - 时间可以包在括号里：`【03:21】`、`[03:21]`、`(03:21)`、`（03:21）`。
  - 时间前后紧挨着数字或冒号时不算（`103:21:5` 这样的不认）。
- **范围**：时间后面紧跟着范围符号（`-`、`–`、`—`、`~`、`～`、`至`、`到`）和第二个时间时，
  例如 `03:21～05:00 掏耳`，只取第一个，第二个跳过。下一段的开头就是这一段的结尾。
- **名字**：
  - 时间（或范围）后面的文字，去掉开头的空白、分隔符（`-–—~～|｜·・:：、，,.。`）
    和右括号，再去掉末尾的空白。
  - 后面没有文字时，用时间前面的文字，同样去掉首尾的空白和分隔符。例如“掏耳 03:21”。
  - 都没有时，这个跳转点没有名字。
- 认不出时间的行忽略。
- 同一次粘贴里两个时间相距不到 1 秒（`SAME_SPOT`），只取先出现的那个。

已知会认错的情况：DLsite 曲目表常写成“01. タイトル (12:34)”，括号里是曲目时长而不是位置。
粘贴框里的识别结果和高亮能让人在添加前看出来，这一版不专门处理。

#### 添加

- 按文件时间添加。时间轴写的是整个录音的时间，所以正在放片段时也一样：
  - 加到片段之外的跳转点照常存下，只是面板里不显示；
  - 提示里写明，例如“已添加 10 个跳转点（其中 3 个在这一段之外）”。
- 跳过的情况：
  - 离已有的跳转点不到 1 秒：算“已有”，不加，也不改已有跳转点的名字。
  - 超出录音时长（按 `effective_duration`）：算“超出时长”，不加。
- 全部加完只写一次盘。在 `MarkStore` 加一个批量添加的方法，一次检查只读和非 UTF-8 路径，
  一次 `entries.set`。
- 添加后回到跳转点面板，光标落在新加的第一个上；提示“已添加 10 个跳转点（2 个已有，1 个超出时长）”。
- 一个也加不了时不关粘贴框，只提示原因：
  - 没认出时间：“没有认出时间，每行写成 03:21 名字”；
  - 都已有或都超出时长：“没有新的跳转点：2 个已有，1 个超出时长”。
- 跳转点文件只读、路径不是 UTF-8 时，和 `b` 一样提示原因。
- 加的都是普通跳转点，不设起点和终点。

### 4. 片段切换时淡出淡入

#### 什么时候淡

只对播放列表里的条目（`Origin::Entry`）：

- **淡出**：条目的结尾在文件结尾之前，也就是片段截在文件中间。
  整首条目、结尾就是文件结尾的片段，录音本来就在那里结束，不淡出。
- **淡入**：条目的开头不在 0:00。从文件开头开始的条目不淡入。
- 只看这一条自己：
  - 列表里最后一条放完停止前，也淡出；
  - 单曲循环重播一个片段，结尾淡出、开头淡入；
  - 从条目面板 `Enter` 开始放一个从中间开始的片段，也淡入。
- 曲库播放（包括队列里的插播）不淡出也不淡入，录音的终点也不淡出，见第 8 节。

#### 怎么淡

- 增益按播放位置算，每个 tick 更新（和睡眠定时一样）：
  - 淡出：离条目结尾不到淡出时长时，增益 = (剩余 / 淡出时长)²，和睡眠定时同一条曲线。
  - 淡入：离条目开头不到淡入时长时，增益 = (已放 / 淡入时长)²。
  - 片段比淡出和淡入加起来还短时，两段各自不超过片段长度的一半。
- 按位置算的结果：
  - 暂停时停在当时的音量。
  - 往后跳越过结尾（`n`、`→`、`L`、`}`、点进度条最右端、系统媒体控制）照旧立刻换下一条，
    不等淡出。
  - 往回跳到开头（`0`、`H`）时，开头那一段也会重新淡入。
- **和睡眠定时一起**：淡出增益分成睡眠定时和片段两份，交给播放器的是较小的那个。
  不相乘：两段重叠时相乘会降得比哪一个都快。
  - `sleep.rs` 的 `set_fade_gain` 改为只记睡眠定时那一份，片段那一份另记，
    合成后再交给播放器。
- **装载时先设好增益再开始放**：要淡入的条目在装载之前就把增益设成 0，不会先漏出一下原音量；
  不淡入的条目设回 1，不会被上一条淡出到 0 的增益压住。装载失败时，按还在放的那一条重新算。
- 停止（列表放完、出错、`stop`）时片段那一份回到 1，下次播放不会没有声音。
- 主循环每 50ms 一个 tick，3 秒淡出约 60 步，每步最多降 3% 左右。验收时听有没有台阶感；
  如果有，再把增益的渐变移到播放器的音频线程里做（第 8 节）。

#### 设置

- `playback { clip-fade 3 }`：淡出的秒数，0–30 的整数；0 关闭淡出和淡入。
- 淡入时长是它的三分之一：3 秒时 1 秒，1 秒时约 0.33 秒。
- 第一次启动生成的 `config.kdl` 写上这一项和说明。旧的配置文件里没有这一行，就用默认的 3。
- 写错时和 `sleep { fade }` 一样：忽略这一项，启动时在底栏提示行号，用默认值。
- 运行中不改，退出时不写回。

### 6. 实现步骤

每步单独提交。提交前在 dev-fedora 容器中通过 `cargo fmt --all -- --check`、
`cargo clippy --all-targets --locked -- -D warnings` 和 `cargo test --all-targets --locked`。

1. **时间轴识别**（新模块 `src/timeline_text.rs`，纯函数，不碰 App）：
   - `parse(text) -> Vec<Parsed { position, name, line }>`，规则见第 3 节。
   - 单元测试：
     - 各种时间写法和不认的写法；全角数字和冒号；括号；范围；
     - 名字取后面、取前面、没有名字，以及分隔符的去除；
     - 同一次粘贴里不到 1 秒的重复；空行和没有时间的行；Windows 换行。
2. **终端粘贴和按键**：
   - `main.rs` 在 Linux 上打开、关闭 bracketed paste（含 panic 钩子），`Event::Paste` 交给
     `Action::Paste(String)`。
   - App 按焦点处理粘贴：单行输入框的换行换成空格，其他地方忽略。
   - `keymap.rs` 的 `Key` 加 `Ctrl(KeyCode)`。没有绑定的 Ctrl 组合键在输入框里不再当作输入，
     现在按 Ctrl+S 会往搜索框里输入一个 s。
   - 测试：往搜索框和改名框里粘贴多行文字；曲库里粘贴不触发任何操作；Ctrl 组合键不进输入框。
3. **粘贴框和空面板**：
   - `MarkStore` 的批量添加；`B` 打开空面板；`sync_marks_panel` 和删除最后一个跳转点不再关面板。
   - `Overlay::PasteMarks`、`Action::PasteMarks`（面板里的 `v`）、粘贴框的输入、`Ctrl+S` 和 `Esc`。
   - 粘贴框和空面板的绘制；面板提示分两行。
   - 测试：
     - `MarkStore`：批量添加的排序、和已有的重复、只读、非 UTF-8 路径、只写一次盘。
     - App：空面板的打开和各按键；添加后光标和提示；全部已有、全部超出时长、没认出时间时不关粘贴框；
       放片段时按文件时间添加并说明有几个在这一段之外；换曲目时空面板的去留。
     - `src/ui/tests.rs`：空面板、粘贴框（高亮、识别结果、放不下时显示最后几行）。
4. **`clip-fade` 设置**：`AppConfig`、`document.rs` 的读取和检查、`template.rs` 的生成和说明。
   - 测试：0–30 和越界的值、生成的模板读回来一致、旧配置文件没有这一行时用默认值。
5. **片段淡出淡入**：
   - 增益分成睡眠定时和片段两份；片段增益的计算；装载前预设增益；停止时复位。
   - 用 `player::fake` 测：
     - 从中间开始的片段装载后增益是 0，放过淡入时长后是 1；
     - 截在中间的片段离结尾 1.5 秒时增益是 0.25；
     - 整首条目、结尾在文件结尾的片段、曲库播放和插播，增益一直是 1；
     - `clip-fade 0` 时不淡；
     - 很短的片段两段各不超过一半；
     - 和睡眠定时“本条”一起时取较小的那个；
     - 淡出到一半按 `n`，下一条的增益从它自己的规则开始，不停在上一条的值；
     - 列表放完停止后增益回到 1，再播放有声音；
     - 装载失败时按原来那一条重新算。
6. **文档**：README（功能、片段播放列表、设置示例）、`packaging/nemuri.1`（KEYS 里的跳转点面板和粘贴框、
   PLAYLISTS、CONFIGURATION）、`changelog.md`，以及本计划的实现记录。

### 7. 验收

用户在自己的 kitty 中，用隔离的 XDG 目录打开 `~/Music`：

- **粘贴时间轴**：
  - 播放一个没有跳转点的长录音，`B` 打开空面板，`v` 打开粘贴框。
  - 从浏览器复制一段 B 站时间轴粘贴进去：整段一次进来，认出的行高亮，识别结果的数目对。
  - `Ctrl+S`：面板里出现带名字的跳转点，`{` / `}` 能在它们之间跳。
  - 再粘贴同一段：提示都已有，粘贴框不关。
  - 时间轴里加一个超出时长的时间：提示超出时长。
  - 在列表里放这个录音的一个片段时粘贴：提示有几个在这一段之外。
- **其他地方的粘贴**：往搜索框粘贴一段多行文字，变成一行；在曲库里粘贴，什么也不发生。
- **片段淡入淡出**：建一个列表，放两三个截在中间的片段和一首整首歌，从头放到尾：
  - 片段结尾 3 秒淡出、下一条 1 秒淡入，没有台阶感和咔哒声；
  - 整首歌的开头和结尾不受影响；
  - `n` 和 `L` 越过结尾时立刻换；
  - 睡眠定时“本条”和片段淡出一起时，音量只降不回升；
  - `config.kdl` 里写 `clip-fade 0` 后不再淡。
- **Windows**（有条件时）：在 Windows Terminal 里往粘贴框粘贴多行时间轴，不会粘到一半就提交。

### 8. 这一版不做

- 交叉淡化（两条重叠着淡出淡入），以及片段之间的无缝衔接。
- 曲库播放时录音终点的淡出：这一版只管播放列表里片段之间的切换。
- 把增益渐变放进音频线程：先用 tick，验收时听出台阶感再做。
- 读系统剪贴板，或读音频旁边的时间轴文件。
- 粘贴框里的光标移动和编辑：只能在末尾输入和退格。
- 粘贴时补上已有跳转点的名字。
- 2.2.0 之后讨论过的其他想法：耳机和锁屏的上一首 / 下一首在跳转点之间切换；读文件内嵌章节
  （MP3 `CHAP`、FLAC cuesheet、MP4 章节）；一键在当前位置设起点终点；播放列表的改名、复制、
  导入导出和把片段排进队列；响度均衡。

### 10. 实现记录

六个提交依次对应第 6 节第 1–6 步。和上面的计划不同或计划没写到的地方：

- **`Key::Ctrl` 挪到第 3 步**：第 2 步只改了“按着 Ctrl 的键不当输入”的规则。新的按键种类要到粘贴框的
  `Ctrl+S` 才用上，提前加会因为没有用到而通不过 `clippy -D warnings`。
  AltGr 打出的字符在 Windows 上带着 Ctrl 和 Alt，所以规则是“按着 Ctrl 且没按 Alt”才算快捷键。
- **识别规则补充**（第 1 步）：
  - 时间前后的冒号只有在冒号外面还是数字时才算连着时间，所以“掏耳：03:21”“03:21：掏耳”都认得，
    `12:30:45:10` 仍不认。
  - 名字两头只去掉开头的右括号和结尾的左括号（多半是时间两边的），整个名字包在一对括号里时去掉这对括号，
    “掏耳（左耳）”保持原样。
  - 名字照原文取，全角数字和冒号只在认时间时换成半角。
  - 时间前面只有序号（“1.”）时不当名字。
- **粘贴框跟着它的那一首**：打开粘贴框后换了曲目（片段放完接下一条、系统媒体控制切歌），粘贴框不关，
  时间轴仍加到打开它时的那一首上；回到的面板是现在这一首的。计划只写了面板换曲目时怎么办。
- **空面板的说明**：放片段时写“这一段里没有跳转点：……”，不写“还没有”。
- **添加后的光标**落在新加的位置最早的那个上，而不是粘贴顺序里的第一个；它在这一段之外时光标不动。
- **其他地方的粘贴**：压成一行时，换行以外的控制字符也换成空格。
- **增益的分工**：新模块 `src/app/fade.rs` 管两份增益的合成、片段增益的计算和淡出曲线，
  睡眠定时的 `fade_gain` 曲线从 `sleep.rs` 挪过来。片段增益在 tick 里按位置算；装载前的预设只在
  `play_item` 里做。会话恢复是暂停着装载的，开始播放前的第一个 tick 就会设好。
  不知道时长时，片段按条目写的结尾淡出。
- **`clip-fade` 的读取**：`sleep { fade }` 原来的读取函数改成通用的“0 到上限的整数秒”，两项共用，
  提示里写各自的名字和上限。
- **帮助**：`b / B` 一行写成“加跳转点 / 跳转点面板（可粘贴时间轴）”，放得下。
- **审查后的修复**（见 `known_issues.md` 的 BUG-011 至 BUG-013）：
  - 片段增益原来在装载前就设上，播放器打开和解码新文件时旧音源会先用上它；改为暂停着装载、
    设好增益再开始放。
  - `0:60:00` 这样小时为 0 的三段式时间原来会被认成 1 小时，三段式现在一律检查分钟。
  - 粘贴框原来每帧都重新识别整段内容，去重还是逐个比；改为内容变了才识别、去重用有序集合。
- **测试数**：完成后 401 个单元测试、21 个播放集成测试。
