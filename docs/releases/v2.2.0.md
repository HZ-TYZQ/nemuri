Nemuri 2.2.0 让 ASMR 长录音更好用：记下喜欢的位置，跳过开场和片尾，再把几个录音里喜欢的段落排成一个播放列表。

## 本次更新

- **跳转点**：10 分钟及以上的录音按 `b` 记下当前位置，`{` / `}` 在跳转点之间前后跳，`B` 打开面板跳转、改名或删除；进度条上用 `|` 标出。
- **起点和终点**：在跳转点面板里按 `s` / `S`，把跳转点设为录音的起点、终点。从头播放时直接从起点开始，播到终点就算播完、接下一首；`0` 先回到起点。
- **片段播放列表**：播放列表的条目可以是整首，也可以是长录音里的一段。在跳转点面板里按 `a`，把从这个跳转点到下一个的一段加进列表；片段从自己的开头放到结尾，显示片段内的时间。
- **列表就是播放范围**：从列表播放时，顺序、循环和随机都在列表里进行，每个列表各记自己的循环方式，新建的列表放完就停。条目面板里可以移动条目、改名、改片段的开头和结尾。
- **修复**：收听进度、跳转点和播放列表文件读不了时不再被覆盖；播放列表没能保存的改动会在下次改动或退出时再写；文件改名后分不清是哪个文件时，不再把记录搬错。

## 升级须知

- 播放列表改用新格式。旧列表照常读取，第一次改动时改写成新格式；改写过的列表 2.0.0 读不了，而在 2.0.0 里新建同名列表会覆盖它，降级前请留意。
- 从播放列表播放不再把后面的条目倒进队列，而是进入这个列表的播放范围；在曲库里按 `Enter` 播放一首就回到曲库。
- 跳转点保存在新文件 `marks.json` 里：Linux 为 `~/.local/share/nemuri/marks.json`，Windows 为 `%APPDATA%\nemuri\marks.json`。
- 2.1.0 没有单独发布，原计划在 2.1.0 里的跳转点、起点和终点都在这一版。

## 下载与安装

- **Fedora 44 x86_64**：下载 `nemuri-2.2.0-1.fc44.x86_64.rpm`，运行 `sudo dnf install ./nemuri-2.2.0-1.fc44.x86_64.rpm`。
- **Windows 11 x86_64**：下载 `nemuri-2.2.0-windows-x86_64-setup.exe`；或解压 `nemuri-2.2.0-windows-x86_64-portable.zip`，运行其中的 `nemuri.cmd`。
- 使用同一 Release 中的 `SHA256SUMS.txt` 核对下载文件。Windows 包尚未签名，SmartScreen 可能提示未知发布者。
