Nemuri（眠り，睡眠）2.0.0 正式接替 Music Player，以按创作者分文件夹整理的 ASMR 长录音为主要场景，也照常播放普通音乐。

## 本次更新

- **睡眠定时**：按 `t` 选 15、30、60、90、120 分钟或“本条播完时”，结束前逐渐淡出，再暂停并保留位置。默认循环方式改为“播完停止”。
- **长录音续听**：10 分钟及以上的录音各自记住进度，下次接着听；曲库显示进度条和“听完”标记，文件改名后重扫也会尝试找回进度。
- **按文件夹听**：按 `f` 筛选创作者文件夹，搜索和顺序、循环、随机播放都限定在其中，下次打开时恢复筛选。
- **直接显示文件名**：曲库、正在播放、队列和系统媒体控制使用不含扩展名的文件名；标签里的标题、歌手和专辑仍可搜索。
- **隐私和声道控制**：按 `i` 隐藏系统媒体控制中的标题和文件路径；`,` / `.` 调整左右平衡，`w` 互换左右声道。
- **修复**：自动切歌时重排队列导致的崩溃、跳转后播放位置停住、窄终端帮助显示不全，以及启动提示被覆盖或截断等问题。

## 从 Music Player 升级

- 命令改为 `nemuri`，手册改为 `man nemuri`，桌面和开始菜单入口改为 Nemuri。
- Fedora RPM 会替换旧的 `music-player` 包；Windows 安装程序沿用原安装目录和 PATH 选项。
- 首次启动时，新目录还不存在就从旧的 `tui-music-player` 目录复制配置、播放列表、会话和收听进度，保留权限与旧文件。Linux 新目录为 `~/.config/nemuri`、`~/.local/share/nemuri` 和 `~/.cache/nemuri`；Windows 为 `%APPDATA%\nemuri` 和 `%LOCALAPPDATA%\nemuri`。缓存会重建。
- Linux 的 MPRIS 总线名改为 `org.mpris.MediaPlayer2.nemuri`；相关脚本请改用 `playerctl -p nemuri`。

## 下载与安装

- **Fedora 44 x86_64**：下载 `nemuri-2.0.0-1.fc44.x86_64.rpm`，运行 `sudo dnf install ./nemuri-2.0.0-1.fc44.x86_64.rpm`。
- **Windows 11 x86_64**：下载 `nemuri-2.0.0-windows-x86_64-setup.exe`；或解压 `nemuri-2.0.0-windows-x86_64-portable.zip`，运行其中的 `nemuri.cmd`。
- 使用同一 Release 中的 `SHA256SUMS.txt` 核对下载文件。Windows 包尚未签名，SmartScreen 可能提示未知发布者。
