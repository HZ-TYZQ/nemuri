Nemuri 2.3.0 让睡前闭着眼听更省心：B 站的时间轴可以整段粘贴成跳转点，播放列表里的片段切换时也不再生硬。

## 本次更新

- **粘贴时间轴**：在跳转点面板（`B`）里按 `v`，把视频简介或评论里的时间轴（每行“03:21 掏耳”）粘贴进去，按 `Ctrl+S` 一次加好全部跳转点和名字。认不出时间的行用暗色显示，下面实时写着认出几个、新增几个；离已有跳转点不到 1 秒的和超出时长的不加。还没有跳转点的录音也能打开面板。
- **片段淡出淡入**：播放列表里截在录音中间的片段，放到结尾前 3 秒淡出，下一段从录音中间开始时 1 秒淡入，不再一刀切断、又突然从另一段声音中间开始。整首和放到文件结尾的片段不淡；时长在 `config.kdl` 的 `playback { clip-fade 3 }` 里改，0 关闭。
- **粘贴**：Linux 上粘贴的内容作为一整段送来，粘贴进搜索框和名字输入框时变成一行；在曲库里不小心粘贴，不再被当成一串快捷键执行。
- **修复**：Linux 上文件名不是 UTF-8 的曲目，重扫或重启后不再变成打不开的路径。

## 升级须知

- 已有的 `config.kdl` 不会自动加上 `clip-fade`，没有这一行时按 3 秒淡出；想改时在 `playback { }` 里加一行。
- 升级后第一次扫描时，会清掉曲库缓存里文件名不是 UTF-8 的旧记录，这些文件会重新读一次标签。
- Windows 上粘贴的内容仍逐键送来。粘贴框里 `Enter` 是换行，多行时间轴照样能粘贴进去，再按 `Ctrl+S` 添加。

## 下载与安装

- **Fedora 44 x86_64**：下载 `nemuri-2.3.0-1.fc44.x86_64.rpm`，运行 `sudo dnf install ./nemuri-2.3.0-1.fc44.x86_64.rpm`。
- **Windows 11 x86_64**：下载 `nemuri-2.3.0-windows-x86_64-setup.exe`；或解压 `nemuri-2.3.0-windows-x86_64-portable.zip`，运行其中的 `nemuri.cmd`。
- 使用同一 Release 中的 `SHA256SUMS.txt` 核对下载文件。Windows 包尚未签名，SmartScreen 可能提示未知发布者。
