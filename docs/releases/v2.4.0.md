Nemuri 2.4.0 继续为睡前闭着眼听：曲库里的长录音在起点和终点处也淡入淡出，起点和终点在播放时按一下就能设好。

## 本次更新

- **起点和终点处淡入淡出**：长录音从起点、或从上次听到的地方开始时 1 秒淡入，放到终点前 3 秒淡出，再接下一首或停下，不会突然出声、也不会被一刀切断。启动时恢复的位置在按空格后同样淡入。越过终点一直放到文件结尾时不淡；跳转照旧立刻出声。时长和片段共用 `config.kdl` 里的 `playback { clip-fade 3 }`，0 一起关掉。
- **一键设起点 / 终点**：播放或暂停长录音时，听到正片开始按 `(`，片尾开始按 `)`，在当前位置设好起点 / 终点，再按一次取消。1 秒以内已有跳转点时直接用它，否则在这里加一个。设好后不跳转；在当前位置设的终点这一遍不会停，一直放到文件结尾。
- **修复**：
  - Linux 上直接关掉终端窗口、或者注销、关机时，这次的播放位置和运行中改过的设置（音量、循环、排序等）不再丢失，退出前照常保存。
  - Linux 上保存设置和收听记录时沿用文件原来的权限，新建的文件只有自己能读写，自己改成 `0600` 的文件不会再变回 `0644`。
  - 删光一个录音的跳转点后，播放列表里截过的片段可以用 `s` / `S` 改回整首。

## 升级须知

- 已有的 `config.kdl` 不用改：`clip-fade` 现在也管起点终点处的淡入淡出，写了 `clip-fade 0` 的话这次新增的淡入淡出也不会有。文件里这一项的说明不会自动更新。
- 以前已经是 `0644` 的设置和数据文件保持不变，想只让自己读写的话用 `chmod 600` 改一次。
- Windows 上直接关掉终端窗口仍然来不及保存，先按 `q` 退出。

## 下载与安装

- **Fedora 44 x86_64**：下载 `nemuri-2.4.0-1.fc44.x86_64.rpm`，运行 `sudo dnf install ./nemuri-2.4.0-1.fc44.x86_64.rpm`。
- **Windows 11 x86_64**：下载 `nemuri-2.4.0-windows-x86_64-setup.exe`；或解压 `nemuri-2.4.0-windows-x86_64-portable.zip`，运行其中的 `nemuri.cmd`。
- 使用同一 Release 中的 `SHA256SUMS.txt` 核对下载文件。Windows 包尚未签名，SmartScreen 可能提示未知发布者。
