## 核心资产

### 正式图标

- SVG 主文件：`assets/icons/nemuri.svg`
- 小尺寸 SVG：`assets/icons/nemuri-small.svg`，只用于 16 px 一档
- 48 px 兼容图标：`assets/icons/nemuri-48.png`
- Windows 多尺寸图标：`assets/icons/nemuri.ico`
- 原始概念稿：`assets/source/icon-concept.png`
- 构图含义：石墨底板上的五柱音频频谱，直接复用 TUI 频谱的画法和配色。去掉终端窗口装饰，保证小尺寸下依然清晰。

SVG 是可维护的主资产。PNG 和 ICO 只作为不支持 SVG 的桌面实现的兼容版本，不应反过来作为修改源。

## Logo 色板

- 底板：`#181B24`
- 频谱低频端：`#A8A8A8`
- 频谱高频端：`#F2F2F2`

Logo 只有两个色彩要素：石墨底板和灰白渐变频谱柱。频谱两端的颜色与 `src/theme.rs` 中默认预设的 `spectrum_low` 和 `spectrum_high` 完全一致。不使用任何彩色、内轮廓、终端符号和分隔线。

## TUI 显示色

以下是默认预设 `default` 的配色；用户可以在配置中换用 `light`、`terminal` 预设或逐项改色，但没有哪个主题能设置全局背景。

播放器界面不绘制全局背景，主要文字使用固定柔和白色，边框和次要信息使用较低亮度的灰白层级。选中行是唯一常驻的局部背景强调，使用 `#343846`。

TUI 使用统一的无彩色显示体系：

- 主要文字：`#F2F2F2`
- 次要文字：`#B8B8B8`
- 边框与分隔线：`#8A8A8A`
- 频谱低频端：`#A8A8A8`
- 频谱高频端：`#F2F2F2`

Logo 与 TUI 默认预设共用同一套灰白频谱色，只有石墨底板是 Logo 独有的：TUI 不绘制全局背景，底板只服务于桌面图标场景。

## 几何规则

- 画布：`1024 × 1024`。
- 底板：从 `(88, 88)` 开始，尺寸 `848 × 848`，圆角半径 `232`。
- 画布四周保留 `88` 单位透明安全区，避免桌面环境裁切。
- 频谱柱：五根，宽 `64`，间距 `64`（柱宽与间距相等，对应 TUI 里每根柱之间的一个空格），整体横跨 `224` 到 `800`。
- 频谱柱高度依次为 `288 / 456 / 344 / 208 / 264`，共用底线 `y = 740`，最高柱在画布中垂直居中。
- 频谱柱使用实心填充和 `12` 的圆角，保持接近 TUI 方块字符的直角观感，同时避免小尺寸下糊成一团。
- 渐变沿水平方向从最左侧柱铺到最右侧柱，对应 `frequency_color` 按下标从低频到高频的线性插值。
- 小尺寸 SVG 只把柱数减到三根（宽 `128`，间距 `128`，圆角 `24`），高度取 `288 / 456 / 264`，底板和配色完全不变。

## 签名细节

Logo 的视觉重点是“石墨底板 + 灰白频谱”。Logo 和播放器界面使用同一套灰白频谱渐变，视觉语言完全统一。

## 使用建议

- 优先使用 SVG。
- 需要固定 48 px 图标时使用随仓库提供的 PNG。
- 等比缩放，保留透明安全区。
- 在浅色和深色背景上都保留完整的深石墨底板。

## 不建议的变化

- 不给 Logo 引入任何彩色，包括早期版本的青紫渐变。
- 不重新加回终端窗口装饰（提示符、窗口圆点、分隔线、内轮廓）。
- 不增加霓虹光晕、投影、玻璃质感或额外音符。
- 不拉伸、压扁或裁掉透明安全区。
- 不改变五根频谱柱的数量和高低节奏。
- 不把频谱柱改回描边画法。
